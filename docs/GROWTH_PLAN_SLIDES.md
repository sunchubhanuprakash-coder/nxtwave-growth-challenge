Paid acquisition only needs to ignite initial seeds ($N_0 \approx 250$). The **Squad Pass** referral engine drives remaining conversions organically ($K \approx 1.08$).

```

          │                                                         │
          ▼                                                         ▼
[Campus Leaderboard] <── [Milestone Rewards Unlocked] <── [Friends Register]
```

### Gamified Milestone Tiers
1. **Tier 1 (1 Friend):** Unlock Masterclass Starter GitHub Template & API Starter Pack.
2. **Tier 2 (3 Friends):** Unlock VIP Mentor Q&A Breakout Room during live workshop.
3. **Tier 3 (5 Friends):** Verified Masterclass Certificate Badge for LinkedIn.
4. **Tier 4 (10 Friends):** 1-on-1 AI Resume & Capstone Project Review by Senior Engineer.

- **Self-referral prevention:** Rejects matching phone numbers or emails.
- **Cycle detection:** Direct and multi-hop referral loops blocked.
- **ICP gating:** Only verified final-year students qualify for leaderboard ranking.
